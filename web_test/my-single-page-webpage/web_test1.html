한국 고전 문양으로 배우는 HTML5 · CSS3 · JavaScript

전통 문양(기와·태극·한지)을 반영한 실습 페이지 — 버튼과 스크롤 기능 포함

HTML5 — 구조 이해

시맨틱 태그(header, main, footer, section)와 접근성(aria)을 직접 사용해보세요.

<header> <main> <footer> <section>
문서 구조 실습
header · main · footer

CSS3 — 스타일과 레이아웃

Flexbox, Grid, 변수, 그라디언트로 한국적 무드(한지·기와·단청) 표현.

display:grid; gap:1rem; background:linear-gradient(...);
한지 질감 배경
repeating-linear-gradient + radial

JavaScript — DOM과 상호작용

이벤트, DOM 조작, 간단한 애니메이션을 직접 구현해보세요.

document.querySelector(...).addEventListener(...)
여기를 클릭하세요
태극 색상으로 애니메이션

학습 순서 예시

  1. HTML 시맨틱 태그로 문서 구조 만들기
  2. CSS로 레이아웃과 색상 테마(전통 문양) 적용하기
  3. JavaScript로 사용자 상호작용 추가하기

각 영역의 "실습 실행" 버튼을 눌러 미리보기를 확인하고, 상단 버튼으로 해당 섹션으로 부드럽게 이동하세요.
