Tetris (tkinter)

A simple, single-file Tetris implemented with tkinter.

Run (Windows PowerShell):

```powershell
python .\tetris.py
```

Controls:
- Left / Right: move piece
- Up: rotate
- Down: soft drop
- Space: hard drop
- p: pause
- q or Esc: quit

No external dependencies required. Requires Python 3.8+ and Tkinter (usually bundled with standard Python installers).
